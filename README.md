# 🚦 Thailand Road Accident Dashboard
## แดชบอร์ดวิเคราะห์อุบัติเหตุทางถนนในประเทศไทย

โปรเจกต์นี้จัดทำขึ้นเพื่อวิเคราะห์ข้อมูลผู้เสียชีวิตจากอุบัติเหตุทางถนนในประเทศไทย
โดยใช้ข้อมูล Open Data จากหน่วยงานภาครัฐจริง และนำเสนอผลในรูปแบบ Dashboard
เพื่อช่วยให้มองเห็นภาพรวม แนวโน้ม และความแตกต่างของสถานการณ์อุบัติเหตุในแต่ละพื้นที่ได้ง่ายขึ้น

> **REAL DATA ONLY**
>
> โปรเจกต์นี้ใช้ข้อมูลจริงจากแหล่ง Open Data ที่สามารถตรวจสอบที่มาได้  
> ไม่มีการสร้างข้อมูลจำลอง (Synthetic Data), Mock Data หรือข้อมูลตัวเลขขึ้นมาเอง

## 🎯 Project Objective

วัตถุประสงค์ของโครงการคือการนำข้อมูลอุบัติเหตุทางถนนมาวิเคราะห์และนำเสนอให้อยู่ในรูปแบบที่เข้าใจง่าย เพื่อช่วยตอบคำถาม เช่น

- พื้นที่ใดมีจำนวนผู้เสียชีวิตจากอุบัติเหตุทางถนนสูง
- ผู้เสียชีวิตมีลักษณะทางประชากรอย่างไร
- จังหวัดหรือภูมิภาคใดมีสถานการณ์ที่ควรให้ความสนใจ
- ข้อมูลอุบัติเหตุมีรูปแบบหรือความแตกต่างอย่างไรในแต่ละพื้นที่

## 🔄 Data Workflow

กระบวนการทำงานของโปรเจกต์แบ่งออกเป็น 4 ขั้นตอนหลัก

### 1. Data Collection

ดาวน์โหลดข้อมูลจากแหล่ง Open Data ของภาครัฐ และเก็บไฟล์ต้นฉบับไว้ใน

```text
data/raw/
```

### 2. Data Validation

ตรวจสอบว่า

- ชุดข้อมูลมีอยู่จริง
- URL ของแหล่งข้อมูลสามารถตรวจสอบย้อนหลังได้
- ไม่มีการใช้ข้อมูลจำลอง
- จำนวนแถวและคอลัมน์ตรงกับข้อมูลที่นำมาใช้

### 3. Data Cleaning

นำข้อมูลมาทำความสะอาดและจัดรูปแบบให้พร้อมสำหรับการวิเคราะห์

ไฟล์ที่ผ่านการเตรียมข้อมูลแล้วอยู่ที่

```text
data/cleaned/rtddi_2567_clean.csv
```

### 4. Data Visualization

นำข้อมูลที่ผ่านการตรวจสอบและทำความสะอาดแล้วไปสร้าง Dashboard
เพื่อช่วยให้ผู้ใช้สามารถทำความเข้าใจข้อมูลได้ง่ายขึ้นผ่านกราฟ ตาราง และตัวชี้วัดต่าง ๆ

## ⚠️ Data Limitations

ชุดข้อมูลที่ใช้ในโปรเจกต์นี้เป็นข้อมูลเกี่ยวกับ

**ผู้เสียชีวิตจากอุบัติเหตุทางถนน ปี 2567**

ดังนั้นข้อมูลบางประเภทอาจไม่มีอยู่ในชุดข้อมูล เช่น

- สาเหตุอุบัติเหตุแบบละเอียด เช่น ขับรถเร็วหรือเมาแล้วขับ
- ชั่วโมงที่เกิดเหตุแบบละเอียด
- จำนวนผู้บาดเจ็บเล็กน้อย
- จำนวนผู้บาดเจ็บสาหัส

โปรเจกต์จะไม่นำข้อมูลที่ไม่มีอยู่จริงมาสร้างหรือประมาณค่าเพิ่มเติม

หากข้อมูลไม่รองรับการวิเคราะห์ใด จะระบุข้อจำกัดไว้แทนการสร้างข้อมูลขึ้นเอง
