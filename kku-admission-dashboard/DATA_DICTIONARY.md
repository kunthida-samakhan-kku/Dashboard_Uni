# Data Dictionary

## 1. High School Students in Khon Kaen Province
- **Dataset**: `dataset_20_47.csv`
- **Source**: data.go.th (สำนักงานจังหวัดขอนแก่น)
- **Variables**:
  - `year`: ปี
  - `province`: จังหวัด
  - `indicator`: ชื่อตัวชี้วัด (จำนวนนักเรียนระดับมัธยมศึกษาตอนปลายหรือเทียบเท่า)
  - `student_count`: จำนวนนักเรียน (คน)
  - `unit`: หน่วย (คน)
  - `source`: แหล่งที่มา (สถิติจังหวัด สนง.สถิติจังหวัดขอนแก่น)

## 2. KKU Admission Data
**ไม่พบข้อมูล Open Data ที่เพียงพอ**
ทางโครงการพยายามค้นหาจากเว็บไซต์ admissions.kku.ac.th, data.go.th และ info.mhesi.go.th แล้ว แต่ไม่พบชุดข้อมูล Open Data ในรูปแบบตาราง (CSV/Excel) ที่สามารถนำมาวิเคราะห์ได้

## 3. Actual Student Background (Study Plan × Faculty)
**ไม่พบข้อมูล Open Data ที่เพียงพอ**
ไม่พบข้อมูล Open Data ที่เปิดเผยเส้นทางการศึกษาระหว่าง "สายการเรียน" และ "คณะที่นักศึกษาเข้าศึกษาจริง" ตามเงื่อนไขที่กำหนด ห้ามมิให้นำข้อมูล "คุณสมบัติที่รับสมัคร" (Admission Eligibility) มาอนุมานแทน Actual Student Background เด็ดขาด
