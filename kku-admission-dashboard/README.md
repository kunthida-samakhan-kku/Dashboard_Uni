# KKU Admission Dashboard

## Project Objective
วิเคราะห์เส้นทางการศึกษาจากนักเรียนระดับมัธยมศึกษาตอนปลาย → การสมัคร KKU → การคัดเลือก → การเข้าศึกษาระดับปริญญาตรี (ภายใต้เงื่อนไขที่ใช้เฉพาะข้อมูลจริงที่เปิดเผยเป็นสาธารณะเท่านั้น)

## Data Sources
- ข้อมูลจำนวนนักเรียนระดับมัธยมศึกษาตอนปลาย จังหวัดขอนแก่น (data.go.th)

## Methodology
ทำการค้นหาข้อมูล Open Data ที่เกี่ยวข้องกับการรับบุคคลเข้าศึกษาของมหาวิทยาลัยขอนแก่น พบว่าไม่มีการเผยแพร่ข้อมูล Open Data เชิงรายละเอียดที่เพียงพอให้วิเคราะห์ได้ตามวัตถุประสงค์โดยไม่ผิดข้อตกลงการใช้งานข้อมูล

## Data Limitations
- **ไม่พบข้อมูล Open Data ที่เพียงพอ** สำหรับข้อมูลการรับนักศึกษาจริงในมหาวิทยาลัยขอนแก่น (จำนวนผู้สมัคร, ผู้มีสิทธิ์เข้าศึกษา, ผู้เข้าศึกษาจริง รายคณะ/สาขา)
- **ไม่พบข้อมูล Open Data ที่เพียงพอ** สำหรับวิเคราะห์ความเชื่อมโยงระหว่างสายการเรียนและคณะที่นักศึกษาเลือกเข้าเรียนจริง (Actual Student Background) 
ทาง Dashboard จึงหลีกเลี่ยงการจำลองข้อมูลขึ้นมาเอง และหลีกเลี่ยงการใช้เงื่อนไขการรับสมัคร (Eligibility) มาแสดงผลให้เกิดความเข้าใจผิดตามกฎของโปรเจกต์

## Installation & How to Run
1. สร้าง Virtual Environment:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```
2. ติดตั้ง Dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. รัน Data Cleaning Script:
   ```bash
   python src/clean_data.py
   ```
4. รัน Streamlit App:
   ```bash
   streamlit run app.py
   ```

## Dashboard Pages
1. **Overview**: สรุปข้อมูล และรายงานข้อจำกัด
2. **Faculty & Major**: แจ้งเตือนข้อจำกัดข้อมูล
3. **Study Background**: แจ้งเตือนข้อจำกัดข้อมูล
4. **Trend**: แนวโน้มนักเรียน ม.ปลาย
5. **Geographic Analysis**: แจ้งเตือนข้อจำกัดข้อมูล
