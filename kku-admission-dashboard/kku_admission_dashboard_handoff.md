# KKU Admission Dashboard — Handoff

## 1. Project Overview
โครงการนี้มีจุดประสงค์เพื่อสร้าง Data Analytics Dashboard วิเคราะห์เส้นทางการศึกษาจากนักเรียนระดับมัธยมศึกษาตอนปลายเข้าศึกษาต่อระดับปริญญาตรีที่มหาวิทยาลัยขอนแก่น โดยใช้ **ข้อมูลเปิด (Open Data) จริงเท่านั้น**

## 2. Main Research Question
นักเรียน ม.6 ที่เข้าศึกษาต่อระดับปริญญาตรีที่มหาวิทยาลัยขอนแก่น ส่วนใหญ่เลือกเรียนคณะอะไร และมาจากสายการเรียนไหน?

## 3. Business Questions
- นักเรียนส่วนใหญ่เลือกเรียนคณะอะไร? (ไม่พบข้อมูล)
- คณะใดมีผู้สมัครมากที่สุด? (ไม่พบข้อมูล)
- คณะใดมีจำนวนรับมากที่สุด? (ไม่พบข้อมูล)
- คณะใดมีการแข่งขันสูงที่สุด? (ไม่พบข้อมูล)
- นักเรียนสายวิทย์–คณิตเลือกคณะอะไร? (ไม่พบข้อมูล)
- สายการเรียนกับคณะที่เลือกมีความสัมพันธ์กันหรือไม่? (ไม่พบข้อมูล)

## 4. Data Sources
1. **High School Students in Khon Kaen**: 
   - **Dataset**: `dataset_20_47.csv`
   - **Source**: สำนักงานจังหวัดขอนแก่น ผ่าน `data.go.th`
   - **URL**: `https://data.go.th/dataset/dataset_20_472`
2. **KKU Admission Data**: ไม่พบข้อมูล Open Data ที่เพียงพอ
3. **Actual Student Background**: ไม่พบข้อมูล Open Data ที่เพียงพอ

## 5. Data Dictionary
รายละเอียดของข้อมูลที่หาได้ โปรดอ้างอิง `DATA_DICTIONARY.md`

## 6. Data Cleaning
ไฟล์ `src/clean_data.py` จะทำการอ่านไฟล์ CSV ที่ถูกดาวน์โหลดมา ซึ่งมีปัญหา encoding เป็น TIS-620/Windows-874 และทำการแปลงให้อยู่ในรูปแบบ UTF-8 ที่สะอาด

## 7. Data Integration
เนื่องจากพบเพียงชุดข้อมูลเดียว จึงไม่ได้มีการ Join ข้อมูลกับชุดข้อมูลอื่นเพิ่มเติม

## 8. Analysis Plan
- แสดงข้อมูลจำนวนนักเรียนระดับมัธยมศึกษาตอนปลายของจังหวัดขอนแก่นย้อนหลัง
- ในส่วนของข้อมูลมหาวิทยาลัยขอนแก่นตาม Business Questions จะระบุอย่างชัดเจนว่า "ไม่พบข้อมูล Open Data ที่เพียงพอ" ตามเงื่อนไขของโครงการ

## 9. Dashboard Structure
- **PAGE 1 — OVERVIEW**: แสดงจำนวนนักเรียน ม.ปลาย จังหวัดขอนแก่น และชี้แจงข้อจำกัดด้านข้อมูลการรับสมัคร KKU
- **PAGE 2 — FACULTY & MAJOR**: ข้อความระบุว่า "ไม่พบข้อมูล Open Data ที่เพียงพอสำหรับวิเคราะห์ข้อมูลระดับคณะและสาขา"
- **PAGE 3 — STUDY BACKGROUND**: ข้อความระบุว่า "ไม่พบข้อมูล Open Data ที่เพียงพอสำหรับระบุว่านักศึกษาที่เข้าเรียนจริงในแต่ละคณะมาจากสายการเรียนใด" ห้ามใช้ Admission Eligibility แทนเด็ดขาด
- **PAGE 4 — TREND**: เทรนด์นักเรียน ม.ปลาย จังหวัดขอนแก่น
- **PAGE 5 — GEOGRAPHIC ANALYSIS**: ข้อความระบุว่า "ไม่พบข้อมูล Open Data ที่เพียงพอสำหรับวิเคราะห์จังหวัดของนักศึกษา KKU"

## 10. Expected Insights
ต้องการค้นหาแนวโน้มจำนวนนักเรียน ม.ปลาย ในจังหวัดขอนแก่น ซึ่งเป็นกลุ่มเป้าหมายหลักของมหาวิทยาลัย แต่ข้อมูลเกี่ยวกับการสมัครและการคัดเลือกเข้าเรียนใน KKU ยังไม่เพียงพอ

## 11. Technical Requirements
โปรเจกต์นี้เขียนด้วย Python (Pandas, Plotly, Streamlit) รันผ่านคำสั่ง `streamlit run app.py`

## 12. Data Limitations
**ข้อจำกัดที่สำคัญที่สุด:**
- ไม่พบข้อมูล Open Data ที่เปิดเผยจำนวนผู้สมัคร, ผู้มีสิทธิ์เข้าศึกษา, หรือจำนวนผู้เข้าศึกษาจริงในมหาวิทยาลัยขอนแก่น ที่จำแนกตามสายการเรียน คณะ หรือสาขา อย่างเป็นทางการที่สามารถนำมาวิเคราะห์ต่อได้
- ตามกฎ ห้ามมิให้สร้างข้อมูลหรือใช้ข้อมูลที่ผิดเงื่อนไขการใช้งาน (เช่น Scraping ที่ไม่อนุญาต) Dashboard จึงจะแสดงเท่าที่มีและแสดงข้อความแจ้งเตือนอย่างชัดเจน
